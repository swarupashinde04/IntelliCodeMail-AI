# IntelliMail AI

AI-powered spam email detection and threat analysis system built using Python, NLP, Machine Learning, and Streamlit with interactive visualization and intelligent risk analysis.

---

## Features

- Spam email detection
- Spam probability analysis
- Risk level prediction
- Suspicious keyword detection
- AI-generated recommendations
- Interactive Streamlit dashboard
- Modern cyber-themed UI
- Real-time email analysis

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- NLP (Natural Language Processing)

---

## Project Workflow

1. User enters an email message
2. Text is converted into numerical features
3. Machine learning model analyzes the email
4. Spam probability is calculated
5. Risk level is generated
6. Suspicious keywords are detected
7. AI recommendations are displayed
